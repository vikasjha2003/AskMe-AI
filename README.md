# AskMe AI

A RAG-based Document Question Answering system that allows users to upload documents and ask questions about their content. The project will also evaluate different **chunking strategies** to measure their impact on RAG performance to help user pick best one for their documents.

## 🚀 Overview

AskMe AI uses **Retrieval-Augmented Generation (RAG)** to retrieve relevant information from uploaded documents and generate context-aware answers.

## 🛠️ Tech Stack

* Python
* LangChain
* ChromaDB
* Hugging Face
* RAGAS
* UV

## 📌 Planned Features

* Document ingestion and processing
* Multiple chunking strategies
* Vector-based retrieval
* LLM-powered question answering
* RAG evaluation and benchmarking
* Comparison of retrieval and answer quality

## 🎯 Goal

To build and evaluate a reliable RAG pipeline while understanding how different document processing and retrieval techniques affect overall performance.
